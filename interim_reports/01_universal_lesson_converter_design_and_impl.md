# 🌈 모두의 수업 변환기 (Universal Lesson Converter) 개발 보고서

- **작성일자**: 2026-10-24
- **개발자**: AI 수석 풀스택 개발자 & 초등 특수교육·UDL 전문가
- **프로젝트명**: 모두의 수업 변환기 (Universal Lesson Converter)
- **핵심 가치**: "같은 목표, 다양한 배움, 모두의 참여"

---

## 1. 프로젝트 배경 및 목표
초등 특수교육 및 통합교육 현장에서는 동일한 단원과 학습목표(예: "자신의 생각과 그 까닭을 표현할 수 있다")를 공유하더라도, 학급 내 학생들의 인지 수준, 읽기 능력, 의사소통 양식(AAC, 구어, 서면), 신체적 운동 기능이 매우 다양합니다.
본 프로젝트는 **보편적 학습설계(UDL: Universal Design for Learning)**의 세 가지 핵심 원리(다양한 방식의 표상, 다양한 방식의 행동과 표현, 다양한 방식의 참여)를 완벽히 구현하여, 교사가 입력한 단 하나의 수업 내용을 4가지 특수교육 맞춤형 학습활동(A형 그림선택, B형 낱말선택, C형 문장완성, D형 자유표현)으로 자동 변환하고 즉시 교실에서 활용할 수 있는 웹 애플리케이션을 구축합니다.

---

## 2. 시스템 아키텍처 및 기술 스택
- **코어 기술**: HTML5, Modern ES6+ JavaScript, Vanilla CSS3 (WCAG 2.1 AAA 준수)
- **영구 데이터베이스**: 브라우저 로컬 데이터베이스 (IndexedDB + LocalStorage 자동 폴백)
  - 교사 수업 데이터, 학생별 맞춤 프로필, AI 변환 활동 세트, 학생 응답 및 성취도 결과 영구 저장
- **AI 및 UDL 변환 엔진**:
  - `ai_engine.js`: 특수교육 교육과정(2022 개정 특수교육 기본 및 공통 교육과정) 기반 스마트 UDL 템플릿/NLP 변환 엔진 내장 (외부 API 없이 100% 오프라인 작동 보장)
  - 확장 API 커넥터: OpenAI(gpt-5-mini/gpt-5-nano) 및 Google Gemini API 키 연동 옵션 제공 (민감정보 마스킹 및 익명화 탑재)
- **접근성 & 멀티모달 인터랙션**:
  - Web Speech API SpeechSynthesis (한국어 자연스러운 음성 TTS, 속도/음높이 조절)
  - Web Speech API SpeechRecognition (D형 자유표현용 음성인식 STT)
  - Web Audio API (외부 음원 파일 의존 없이 실시간 합성되는 긍정적 강화 효과음 및 팡파르)
  - HTML5 Canvas 그리기 인터페이스 (소근육 및 시각적 표현 지원)
- **인쇄 및 PDF**: `@media print` A4 규격 학습지 최적화 레이아웃 (정답지, 활동지, 점자/큰글자 대응)

## 3. 핵심 4가지 학습활동 유형 설계
1. **A형: 그림 선택형 (Picture Selection)**
   - 대상: 그림 중심 읽기, 직관적 터치 선호, 많은 지원 필요 학생
   - 방식: 큰 이미지/상징과 2~4지선다 그림 카드 터치, 음성 단서 지원
2. **B형: 낱말 선택형 (Word Matching & Cloze)**
   - 대상: 낱말 수준 읽기, 낱말 재인 및 어휘 학습 단계 학생
   - 방식: 낱말 카드 짝맞추기, 낱말 고르기, 쉬운 빈칸 채우기
3. **C형: 문장 완성형 (Sentence Completion)**
   - 대상: 짧은 문장 읽기 가능, 문장 구조화 지원 필요 학생
   - 방식: 문장 틀(Sentence Frame) 제공 ("나는 [계절]이 좋다. 왜냐하면 [이유] 때문이다."), 보기 카드 드래그/클릭 채우기
4. **D형: 자유 표현형 (Free Expression)**
   - 대상: 문단 수준, 다양한 매체로 자기 표현이 가능한 학생
   - 방식: 텍스트 입력, 마이크 음성 녹음/텍스트 변환, 캔버스 그림 그리기 복합 모드

## 5. 결론 및 교육적 의의
- **교육적 가치**: 한 학급에서 다양한 인지 수준을 가진 특수교육대상학생과 일반학생이 '같은 목표'를 공유하면서도, 각자의 발달 단계와 표현 양식에 부합하는 '다양한 배움'을 경험할 수 있습니다.
- **기술적 완성도**: 외부 서버나 복잡한 설치 없이 브라우저 자체 API(IndexedDB, Web Speech API, Web Audio API, Canvas API)만으로 완전히 자립적인 구동이 가능하여 교실 현장의 활용성과 접근성을 극대화하였습니다.
