# 🌈 모두의 수업 변환기 (Universal Lesson Converter)
> **핵심 가치: "같은 목표, 다양한 배움, 모두의 참여"**  
> 초등 특수교육대상학생을 위한 AI 기반 보편적 학습설계(UDL) 맞춤형 웹 애플리케이션

---

## 📖 1. 프로젝트 개요

**모두의 수업 변환기**는 교사가 **하나의 학습목표와 수업 내용**을 입력하면, 초등 특수교육대상학생의 **학습 수준(읽기/의사소통/지원정도)**에 맞춰 4가지 맞춤형 학습활동으로 즉시 자동 변환하는 풀스택 웹 애플리케이션입니다.

- **기본 탑재 데모**: 초등 3학년 국어 [3국01-03] "자신의 생각과 그 까닭을 표현할 수 있다" (단원: 3. 생각을 나누어요 / 주제: 내가 좋아하는 계절과 그 까닭)
- **보편적 학습설계(UDL: Universal Design for Learning)** 철학을 적용하여 장애 유무나 학습 속도에 구애받지 않고 모든 학생이 같은 목표를 향해 성공적으로 수업에 참여할 수 있도록 돕습니다.

## 🌟 2. 핵심 기능

### ① 수업 만들기
- **교육과정**: 공통교육과정 / 특수교육 기본 교육과정 연계
- **학년**: 초등 1~6학년 선택
- **교과**: 국어, 수학, 사회, 과학, 안전한 생활, 슬기로운 생활 등
- **수업 정보 입력**: 학습목표, 수업 주제, 본문 지문, 핵심 어휘

### ② 학생별 맞춤 설정 (개별화 프로필)
- **읽기 수준**: 그림 중심 / 낱말 수준 / 짧은 문장 / 문단 수준
- **의사소통 방식**: 그림 선택 / 낱말 선택 / 문장 완성 / 음성 표현 / 글쓰기
- **지원 정도**: 많은 지원 / 부분적 지원 / 최소한의 지원 / 독립 수행
- **세부 옵션**: 2~4지선다 개수 조정, 힌트 버튼 제공 여부, TTS 자동 읽기, 글자 크기, 고대비 모드

### ③ UDL 기반 4가지 학습활동 자동 변환
| 유형 | 명칭 | 대상 수준 | 활동 방식 및 특징 |
| :---: | :---: | :---: | :--- |
| **A형** | **그림 선택형** | 그림 중심 / 많은 지원 | 직관적인 큰 그림과 상징(이모지)을 터치하여 생각과 까닭 선택 |
| **B형** | **낱말 선택형** | 낱말 수준 / 부분 지원 | 핵심 어휘 낱말 카드 짝맞추기, 문장 속 빈칸 채우기 |
| **C형** | **문장 완성형** | 짧은 문장 / 최소 지원 | 문장 틀(`나는 [생각]이 좋다. 왜냐하면 [까닭] 때문이다.`)을 채워 완결된 문장 구성 |
| **D형** | **자유 표현형** | 문단 수준 / 자율 표현 | 글(타이핑), 말(마이크 음성인식 STT), 그림(캔버스 그리기) 3-Way 멀티모달 자기표현 |

### ④ 교사용 편집 및 검토 기능
- AI 변환 문항의 지시문, 음성 안내문(TTS), 정답, 선택지, 힌트, 해설 실시간 수정
- 문항 추가, 삭제, 순서 변경 (위/아래 이동)
- 학생 맞춤 프로필 적용 미리보기 및 수업 복제/재사용

### ⑤ 학생용 학습 화면 (집중 모드)
- 한 화면에 하나의 문항만 제공하여 시각적 복잡성 최소화
- 태블릿 및 스마트폰 터치에 최적화된 48px 이상의 대형 버튼
- **음성 읽어주기(TTS)**: 한국어 명료한 속도(0.85배속)로 문제 읽기
- **실시간 청각/시각 피드백**: Web Audio API 기반 맑은 도-미-솔 차임벨 & 격려음
- 단계 완료 시 신나는 축하 트로피 애니메이션 및 팡파르 효과음

### ⑥ 웹 접근성 및 보조공학 (WCAG 2.1 AAA 준수)
- **글자 크기 3단계**: 보통(16px), 크게(18px), 아주 크게(22px) 상시 전환
- **고대비 모드**: 저시력 학생을 위한 블랙 & 옐로우 고대비 인터페이스
- **음성 인식(STT)**: 키보드 입력이 어려운 학생을 위한 마이크 음성 타이핑
- **키보드 조작 완벽 지원**: 숫자키 1~4번 선택, Enter/방향키 이동, Esc 닫기

### ⑦ 데이터베이스 및 학습 결과 분석
- **브라우저 영구 데이터베이스(IndexedDB)** 내장으로 별도 DB 서버 없이 데이터 영구 보관
- 학생 이름 대신 **익명 코드**(꿈나무-01, 사랑-02 등)를 사용하여 민감정보 철저 보호
- 활동별 정답률, 소요 시간, 교사 지원 정도(독립/최소/부분/전면) 기록
- 유형별 평균 성취도 캔버스 그래프 제공
- **CSV 데이터 내보내기**: `utf-8-sig` 인코딩으로 엑셀 한글 깨짐 방지

### ⑧ A4 세로 인쇄 및 PDF 저장
- `@media print` 스타일시트를 통해 불필요한 웹 UI를 자동으로 제거하고 **A4 규격 학습지** 양식으로 출력
- A·B·C·D형 활동지를 개별 선택하거나 한 번에 인쇄/PDF 저장 가능

## 🚀 4. 실행 및 배포 방법

### ① 바로 실행하기 (별도 설치 불필요!)
1. 컴퓨터나 태블릿의 파일 탐색기에서 **`index.html`** 또는 **`standalone.html`** 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari) 브라우저로 엽니다.
2. 학생 전용 태블릿에는 **`student.html`**을 바로 열어주면 교사용 메뉴 없이 즉시 활동을 수행할 수 있습니다.

### ② 웹 호스팅 및 배포
- **GitHub Pages**: 본 폴더의 파일들을 GitHub 저장소에 올리고 `Pages` 기능을 켜면 즉시 무료 호스팅 URL 생성
- **Vercel / Netlify**: 본 폴더를 드래그 앤 드롭하기만 하면 10초 만에 전 세계 어디서든 접속 가능한 링크 생성

## 🔒 5. 개인정보 보호 및 외부 AI 연동 안내

- 본 시스템은 학생의 이름, 주민번호, 장애 진단 등 민감정보를 수집하지 않으며 오직 **익명 코드**(예: `꿈나무-01`)로만 관리됩니다.
- 외부 AI(OpenAI `gpt-5-mini` 또는 Gemini) API 키를 교사 설정에 등록하더라도, **학생의 개인정보나 장애 정보는 일체 외부 서버로 전송되지 않으며** 오직 교육과정의 학습 내용과 문항 구조화 요청만 전달됩니다.
- 외부 API 키가 없어도 **내장된 지능형 UDL 규칙 엔진**이 100% 오프라인으로 고품질 활동을 즉시 생성합니다.
